# Mario Kart Tour: Free Roam 🏎️🏙️

Um ambiente em Three.js para exploração livre do mapa **New York Minute** extraído do game *Mario Kart Tour*.

## 🚀 Funcionalidades
- **Câmera Modo Livre (Fly Cam)**: Navegue pelo mapa usando teclado e mouse.
- **Leitor Zip / OBJ / FBX / PNG**: Descompactação e carregamento dinâmico do modelo e das texturas de iluminação/bake (`Bake_Cnsw_21_g00_b00_f00.png`).
- **Navegação WebGL**: Desenvolvido em JavaScript puro com Three.js.

## 🕹️ Controles
- **W / A / S / D**: Mover câmera (Frente / Esquerda / Trás / Direita)
- **Q / E**: Subir / Descer
- **Arrastar Mouse (Botão Esquerdo)**: Olhar ao redor
